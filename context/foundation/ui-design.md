# UI Design

## Design Vision

FitSpotApp should feel calm, modern and premium rather than aggressive or "gym-focused".

The interface should communicate:
- simplicity
- wellness
- trust
- clarity
- ease of booking

The visual direction is inspired by Scandinavian minimalism with subtle olive-green accents instead of highly saturated fitness colors.

# Style Guidelines

## Look & Feel

The application should feel:

- modern
- calm
- premium
- minimal
- approachable

Avoid high saturation and overly energetic colors.

The interface should resemble a wellness product rather than a bodybuilding application.

---

## White Space

Generous spacing should be preferred over dense layouts.

Components should breathe.

---

## Cards

- White background
- Large border radius (16–20px)
- Very subtle shadow
- Plenty of padding

---

## Icons

Simple outline icons.

Use the dark olive accent only for active states.

---

## Navigation

Navigation should remain mostly neutral.

Only the active item should use the olive accent.

---

## Typography

Modern sans-serif.

Recommended fonts:

- Inter
- Geist
- Manrope

---

# Accessibility

- Maintain WCAG AA contrast ratios.
- Never rely solely on color to communicate status.
- Interactive elements should always include hover and focus states.
- Semantic colors (success, warning, error) should remain consistent across the application.
